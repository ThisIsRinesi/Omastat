# skwd-wall Theme Integration

Omastat can read Material/Matugen colors generated by skwd-wall from these
locations, in order:

```text
${XDG_CONFIG_HOME:-~/.config}/omastat/theme/colors.json
${XDG_CONFIG_HOME:-~/.config}/omastat/theme/matugen.json
${XDG_CONFIG_HOME:-~/.config}/skwd-wall/colors.json
${XDG_CACHE_HOME:-~/.cache}/skwd/colors.json
${XDG_CACHE_HOME:-~/.cache}/skwd-wall/colors.json
```

The built-in skwd-wall and skwd integrations usually cover the generic paths.
Use `omastat-colors.json` if you want a dedicated Omastat output with priority
over those cache files:

```json
{
  "name": "omastat",
  "template": "omastat-colors.json",
  "output": "~/.config/omastat/theme/colors.json"
}
```

Place the template in your skwd-wall templates directory, then add the snippet
to the `integrations` array in `~/.config/skwd-wall/config.json`. Restart
`omastat tui` or press `r` in the TUI after changing wallpapers.
