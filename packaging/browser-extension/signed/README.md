# Signed Nagori browser extension

`nagori-domain-tracker-firefox.xpi` is the signed version 0.4.0 release. Its extension ID is `nagori-domain-tracker@thisisrinesi.github.io`; its native host is `io.github.thisisrinesi.nagori`.
